# Sunless Skeleton

Sunless Skeleton is a Minecraft plugin that introduces a unique skeleton mob variant that does not burn in sunlight and has the ability to shoot lightning from its bow. This plugin enhances the vanilla Minecraft experience by adding a new, powerful enemy to your world.

## Install

1. Download the plugin JAR file from the releases section of the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to enable the plugin.

## Use

1. Spawn the Sunless Skeleton in your world using the appropriate command or spawn egg.
2. Observe the skeleton's unique behavior: it does not burn in sunlight and can shoot lightning from its bow.
3. Enjoy the enhanced combat experience with this powerful mob variant.
